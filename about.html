About关于本站

碳网图谱 CarbonNet 是一个面向「碳材料超级电容器三维导电网络」方向的 文献知识站，提供领域知识脉络、知识关系图、文献库与性能数据面板， 并通过 GitHub Actions 每周自动抓取最新文献。

数据来源

文献元数据（标题、作者、期刊、年份、被引次数、摘要、研究概念）来自 OpenAlex—— 由非营利机构 OurResearch 维护的开放学术索引，以 DOI 为基准聚合了 Crossref、ORCID、机构库等来源，覆盖 Web of Science / Scopus 收录的期刊文献， 被引数据与 WoS 同源（引用关系均来自 Crossref/DOI 引用图）。

Web of Science 官方 API 需机构订阅授权，不提供公开访问，因此本站以 OpenAlex 作为开放替代。 如需使用自己学校/单位的 WoS 数据，可将 WoS 导出的「制表符分隔 (Win/UTF-8)」文件 用本站脚本导入合并——见下方说明。

文献筛选标准

  • 检索范围：24 组定向检索式（核心 12 组 + 补充 12 组，如 "3D conductive network" supercapacitor、氮掺杂多孔碳、高负载电极、微型超级电容器、MXene 复合等），限定 2010 年以来的研究文章与综述（经典文献清单不受此限，含 1997 年起奠基之作）；
  • 双通道收录：每组检索式按「被引降序」取经典文献 + 按「日期降序」取近三年新文献，兼顾经典性与前沿性；
  • 权威期刊标记：内置本领域 WoS/JCR Q1 主流期刊清单（Nature 系列、Advanced Materials、ACS Nano、Energy & Environmental Science、Carbon 等 70 余本），标记为「Q1 权威期刊」；
  • 经典文献专栏：专家整理的 25 篇领域奠基之作（Simon & Gogotsi《Materials for electrochemical capacitors》、Chen《Three-dimensional flexible and conductive interconnected graphene networks》等），逐篇附中文点评，首页「领域经典文献」栏目与文献库「★ 仅经典文献」筛选均可查看；
  • 自动标签：按受控词表（材料/策略/指标/应用四类共 36 个标签）对每篇论文的标题与摘要做正则匹配，支撑关系图与筛选；
  • 性能数据抽取：从摘要自动提取报道的最大比电容 (F/g)、能量密度 (Wh/kg)、功率密度 (W/kg)，用于性能分布统计（数值仅供参考，请以原文为准）。

Web of Science 导出文件导入

在 WoS 检索结果页选择「导出 → 制表符分隔文件 (Win, UTF-8) → 全记录与引用的参考文献」， 得到 savedrecs.txt 文件后运行： 

python scripts/import_wos.py 路径/to/savedrecs.txt
python scripts/build_data.py

导入的文献会标记 source: "WoS" 并与现有 OpenAlex 数据按 DOI 去重合并， 每周自动更新不会覆盖这些记录。

自动更新机制

  • 每周一 02:30 UTC（北京时间 10:30），GitHub Actions 工作流 .github/workflows/update-papers.yml 自动运行「抓取 → 中文化翻译 → 建库」流水线；
  • 标题与摘要由翻译步骤自动中文化（英文原文保留，可在文献库中展开查看），新入库文献自动获得中文；
  • 新数据提交到仓库后，GitHub Pages 自动重新部署站点（无需人工干预）；
  • 也可在 GitHub 仓库 Actions 页手动触发 workflow_dispatch 随时更新；
  • 本仓库无任何依赖：Python 脚本仅用标准库，前端仅依赖本地 vendored 的 ECharts。

使用提示

  • 知识脉络：点击节点展开/收起，点击带说明的节点查看解读，最细分方向附代表论文；
  • 关系图：拖拽节点、滚轮缩放，点击文献节点直达 DOI 原文；
  • 文献库：支持全文搜索、年份/期刊质量/类型/标签/经典文献筛选与 CSV 导出；
  • 所有图表适配深色/浅色两种主题（右上角切换）。
